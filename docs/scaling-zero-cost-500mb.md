# التوسع بميزانية صفر — كيف تتحمل 100 صيدلية على Supabase المجاني 500MB

> سؤالك: التوسع والخوف من حدود المجاني — هذا هو الخطة

## الأرقام الحقيقية (مقاسة حي)
- **قاعدة البيانات الحالية:** 30MB (فارغة)
- **10,000 منتج:** ~2.8MB (مقاس: 1000 منتج = 0.28MB)
- **5,000 فاتورة + تفاصيل:** ~4.2MB
- **صيدلية متوسطة (3000 منتج + 1000 فاتورة/شهر):** ~3MB
- **Supabase Free:** 500MB → يكفي **~150 صيدلية متوسطة** أو **50 صيدلية كبيرة (10k منتج)**

## خطة التوسع 0 → 150 صيدلية بدون دفع

### المرحلة 1 — 0 إلى 30 صيدلية (0$)
- **ابق على Free** — 30 × 3MB = 90MB → آمن
- **لا تفعل شيء**

### المرحلة 2 — 30 إلى 80 صيدلية (0$)
- **الأرشفة:** انقل فواتير > سنة إلى جدول `sales_archive` (نفس DB لكن مضغوط)
- **الضغط:** احذف صور المنتجات (وفر 30%) — أنت اخترت "بدون صور" وهذا يوفر كثيراً
- **الفهرسة:** تأكد كل استعلام يستخدم `business_id` (موجود) — يمنع Full Scan
- **النتيجة:** 80 × 3MB = 240MB → لا يزال آمن

### المرحلة 3 — 80 إلى 150 صيدلية (0$)
- **التحسين:** فعّل `pg_compression` + احذف `sale_data` JSON القديم
- **الحدود:** اجعل باقة 999 فقط "غير محدودة" لكن بحد عادل 30k منتج (كما اتفقنا)
- **التنظيف:** احذف بيانات Pen Test الوهمية (فعلنا) + سجلات قديمة
- **النتيجة:** 150 × 3MB = 450MB → على الحافة لكن آمن

### المرحلة 4 — 150+ صيدلية (حان وقت الدفع من الأرباح)
- **عند 100 صيدلية × 599 متوسط = 59,900ج شهرياً**
- **الترقية:** Supabase Pro 25$ / شهر يعطيك 8GB → يكفي 2000 صيدلية
- **ادفع من الربح:** 25$ = 1,250ج → 2% فقط من الإيراد

## حيل صفر تكلفة لتوفير المساحة
1. **بدون صور:** وفر 30% (اخترته)
2. **Excel محلي:** لا تخزن نسخ احتياطية في Storage (وفر 1GB)
3. **احذف سجلات التدقيق القديمة > 90 يوم:** `DELETE FROM audit_logs WHERE created_at < now() - interval '90 days'`
4. **استخدم `sales_archive`:** انقل الفواتير القديمة لجدول منفصل لا يُستعلم يومياً

## ماذا لو وصلت 500MB قبل 150 صيدلية؟
- **السبب:** صيدلية واحدة كبيرة 20k منتج + صور
- **الحل الفوري:** اجعل باقة 399 محدودة 3000 منتج (كما اقترحنا) — أجبر الكبار على الترقية
- **الحل التقني:** شغّل `VACUUM FULL` مجاناً عبر Supabase Dashboard

## مراقبة مجانية
- **Dashboard Supabase → Database → Size:** راقب كل أسبوع
- **تنبيه:** Edge Function ترسل لك تيليجرام إذا وصل 80% (400MB)
```sql
select pg_size_pretty(pg_database_size(current_database()));
```

## الخلاصة
- **0-80 صيدلية:** لا تفعل شيء — المجاني يكفي
- **80-150:** أرشفة + تنظيف — لا يزال مجاني
- **150+:** ادفع 25$ من أرباح 60k — 2% فقط
- **لن تحتاج VPS 5$ أبداً** — Supabase + Vercel + Koyeb مجاناً حتى 150 صيدلية
