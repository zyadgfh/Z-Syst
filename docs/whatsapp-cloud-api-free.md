# واتساب حقيقي بميزانية صفر — WhatsApp Cloud API المجاني

> طلبت واتساب حقيقي وليس تيليجرام — هذا هو الحل الوحيد المجاني والرسمي بدون حظر.

## WhatsApp Cloud API — الباقة المجانية الحقيقية (2026)
- **المزود:** Meta مباشرة (لا وسيط)
- **التكلفة:** 1000 محادثة مجانية كل شهر — تكفي 50-100 صيدلية في البداية (الصيدلية ترسل 5-10 رسائل دعم شهرياً)
- **بعد 1000 محادثة:** 0.02-0.05$ لكل محادثة — تدفع فقط عندما تربح
- **المتطلبات:** حساب Facebook Business + رقم هاتف (يمكن رقم مجاني من Meta) + توثيق بسيط (سجل أو بطاقة)
- **الاستضافة:** Supabase Edge Function مجانية تستقبل webhook — لا VPS

## لماذا هذا وليس Baileys غير الرسمي؟
|  | Cloud API الرسمي | Baileys غير رسمي |
|---|---|---|
| الحظر | مستحيل (رسمي) | يحظر الرقم فجأة |
| التكلفة | 1000 مجاناً | 0 لكن مخاطرة |
| الاستقرار | 99.9% | ينقطع |
| يحتاج VPS ينام؟ | لا | نعم |

## خطوات الإعداد بميزانية صفر (ساعة واحدة)

### 1) إنشاء التطبيق (10 دقائق)
1. developers.facebook.com → إنشاء App → نوع Business
2. أضف منتج WhatsApp → احصل على Phone Number ID و Token مؤقت
3. احفظ في Supabase Secrets: `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_ID`

### 2) Edge Function مجانية (20 دقيقة)
- `supabase/functions/whatsapp-bot/index.ts` — تستقبل رسالة الصيدلي → تبحث في FAQ → ترد تلقائياً
- مثال: الصيدلي يرسل "فاتورة" → البوت يرد بفيديو "كيف تطبع فاتورة 30ث"
- لو لم يفهم: يفتح تذكرة في `support_tickets` ويرسل لك إشعار

### 3) ربط الرقم (10 دقائق)
- في لوحة Meta → Webhook URL = `https://atvttthrqsybjjwrbiyl.supabase.co/functions/v1/whatsapp-bot`
- Verify Token = كلمة سر تختارها

## سيناريو دعم واقعي
1. الصيدلي يحفظ رقم Z-Syst واتساب: `+20 1xxxxxxxxx`
2. يرسل "المخزون ناقص" → البوت يرد فوراً: فيديو 30ث + زر "افتح النواقص"
3. لو كتب "مشكلة فنية" → تذكرة تُفتح → تصلك على واتساب → ترد → يصله الرد

## ماذا لو تجاوزت 1000 محادثة؟
- 1000 محادثة = حوالي 100 صيدلية × 10 رسائل — ستكون ربحت 39900ج على الأقل
- تكلفة 100 محادثة إضافية = ~3$ — تدفعها من الربح
- بديل مجاني: حوّل المحادثات الزائدة لتيليجرام أو شات داخلي تلقائياً

## الخلاصة بميزانية صفر
- **الـ 10 الأوائل:** رد يدوي واتساب عادي (رقمك الشخصي) — صفر إعداد
- **من 10 إلى 100:** فعّل Cloud API المجاني (1000 محادثة) + بوت FAQ — صفر تكلفة
- **بعد 100:** ادفع 3-5$ من الأرباح أو حوّل لتيليجرام

> لا تستخدم Baileys — سيُحظر رقمك وتخسر ثقة الصيدليات. Cloud API هو الواتساب الحقيقي المجاني.
