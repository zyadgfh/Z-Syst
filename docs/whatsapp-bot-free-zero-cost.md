# بوت دعم مجاني 100% بميزانية صفر — بديل واتساب

## الحقيقة بميزانية صفر
- **واتساب Business API الرسمي** = يحتاج توثيق Meta + رقم + تكلفة لكل محادثة (ليس صفر)
- **واتساب غير رسمي (Baileys)** = مجاني لكن يحظر الرقم فجأة — خطر لصيدلية
- **الحل المجاني الآمن:** تيليجرام بوت + شات داخل Z-Syst + فيديوهات

## الحل المقترح (صفر تكلفة، لا ينام)

### 1) تيليجرام بوت مجاني (الأساسي)
- **التكلفة:** 0 — Telegram Bot API مجاني للأبد
- **الإنشاء:** 5 دقائق عبر @BotFather
- **الربط:** Supabase Edge Function (Deno مجاني) يستقبل رسائل البوت ويرد
- **الاستخدام:** الصيدلي يرسل "المخزون ناقص" → البوت يرد تلقائياً برابط فيديو + خطوات
- **الميزة:** لا حظر، لا تكلفة، يعمل حتى مع ضعف النت

### 2) شات داخل Z-Syst نفسه (مجاني)
- **التقنية:** جدول `support_tickets` في Supabase (موجود) + Realtime مجاني
- **الواجهة:** زر "مساعدة" في كل صفحة يفتح شات
- **التخزين:** رسائل الشات في Postgres (ضمن 500MB المجاني) — 1 رسالة = ~0.5KB → 1M رسالة = 500MB
- **الإشعار:** Edge Function ترسل إشعار تيليجرام لك عند كل تذكرة جديدة

### 3) مكتبة فيديوهات FAQ (تحل 90% من الدعم)
- **فيديوهات 30 ثانية لكل مشكلة شائعة:** "كيف أضيف مورد"، "كيف أطبع فاتورة"، "النت فصل"
- **التخزين:** يوتيوب مجاني (غير مدرج) + رابط داخل النظام
- **البوت يرسل الفيديو المناسب تلقائياً** عند كلمات مفتاحية

## كيف ننفذ بميزانية صفر في يوم واحد

### الخطوة 1 — إنشاء بوت تيليجرام (5 دقائق)
```
1. افتح تيليجرام → @BotFather → /newbot → اسم: Z-Syst Support
2. احفظ التوكن: 123456:ABC...
3. أضف التوكن في Supabase Secrets: TELEGRAM_BOT_TOKEN
```

### الخطوة 2 — Edge Function مجانية (30 دقيقة)
- ملف `supabase/functions/telegram-bot/index.ts` (Deno)
- يستقبل webhook من تيليجرام → يبحث في FAQ → يرد
- لا تحتاج VPS — Supabase Edge Functions مجانية (500k طلب/شهر)

### الخطوة 3 — شات داخل النظام (ساعة)
- جدول `support_tickets` موجود بالفعل
- أضف Realtime subscription في Frontend (Vercel مجاني)
- زر "مساعدة" يفتح Drawer

## ماذا يرى الصيدلي؟
1. في Z-Syst: زر "مساعدة" → يكتب "الباركود لا يعمل" → رد فوري برابط فيديو 30ث
2. لو لم يحل: تذكرة تُفتح → تصلك على تيليجرام → ترد من تيليجرام → يصله الرد داخل النظام
3. كل المحادثة محفوظة في Supabase — ترجع لها أي وقت

## لماذا هذا أفضل من واتساب بميزانية صفر؟
- واتساب يدوي = سترد على 100 صيدلية واتساب ليل نهار → ستنهار
- بوت تيليجرام + FAQ = 90% من الأسئلة تُحل تلقائياً بدون تدخل
- الشات الداخلي = لا تشتت بين واتساب وتيليجرام وفيسبوك — كل الدعم في مكان واحد
