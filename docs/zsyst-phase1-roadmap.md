# Z-Syst Phase 1 Blueprint

## Goal
Create a scalable core foundation for a multi-tenant pharmacy SaaS platform.

## Phase 1 scope
- Multi-tenant drug directory
- Drug alternatives and search
- API-first module structure
- Migration-based schema foundation
- Basic test coverage for core endpoints

## Database schema
- drugs
- drug_alternatives
- company_id/business_id tenant fields
- barcode and name indexes for fast search

## Roadmap
1. Phase 1 — Core foundation and drug directory
2. Phase 2 — Inventory and stock movement
3. Phase 3 — POS and sales workflow
4. Phase 4 — Purchasing and supplier management
5. Phase 5 — CRM, loyalty, and doctor insights
6. Phase 6 — AI assistant, analytics, offline sync, and mobile app
